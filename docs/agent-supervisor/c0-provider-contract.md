## Environment profile

The prior union allowlist could pass unrelated Bedrock, Vertex, Foundry, and
custom-gateway settings into a direct Anthropic process. C0 replaces it with
an explicit backend profile. The only names the selected process may receive
are:

- `ANTHROPIC_API_KEY`;
- `LANG` and `LC_ALL`;
- `PATH`; and
- `TMPDIR`.

No value is written to Git or audit output. `ANTHROPIC_BASE_URL`, AWS, Google,
Bedrock, Vertex, Foundry, W&B, SSH, and unrelated environment variables are
excluded. An unsupported backend fails closed. Passing an explicit empty
environment also remains empty instead of accidentally inheriting the parent
process.

## C1 handoff

C1 is the first paid external call. Before it begins, the user must explicitly
authorize the one-slot USD `0.5` ceiling. C1 must then build and persist one
curated D1 context, perform a read-only Git-state check before and after the
tool-free call, and retain the valid or invalid structured result through the
same local controller. Credential presence is intentionally not tested or
recorded in C0; C1 must fail closed if the direct Anthropic credential is not
available.
